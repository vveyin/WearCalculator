# 🐾 嗷呜计算器 (WearCalculator)

![Last Version](https://img.shields.io/github/release/NickWoluff/WearCalculator/all.svg?style=flat-square&color=brightgreen)

**专为智能手表打造的高精度计算器，嗷呜！**

## ✨ 核心特性 (Features)

- 多类屏幕适配：深度适配方屏、圆屏，根据手表屏幕类型自动适配应用界面。
- 超高精度计算：底层重构为纯 BigDecimal 高精度数学引擎，彻底消除二进制浮点运算误差。
- 丝滑无界滚动：当算式或结果过长时，旋转表冠或左右滑动即可查看完整数据，再也不怕屏幕装不下。
- 防呆纠错逻辑：内置严谨的输入互锁机制，拒绝无意义的 Error 崩溃。
- 现代交互界面：遵循 Material Design 极简美学，美观易用。
- **科学计算模式**：点一下顶部时间即可切换按键内容，加减乘除之外还支持乘方、括号、阶乘、
  三角函数、对数、取模、圆周率与自然常数。

## 🧮 科学计算模式

### 怎么切换
点一下界面顶部显示时间的那一行，按键会在「普通」和「科学」两套内容之间循环切换。
按键位置一个都没动，只是换了功能：

圆屏（466×466）上按键是弧形排布，一共四排：

```text
行1    C     7     8     9     ÷     ⌫
行2          4     5     6     −     ×
行3          1     2     3     +
行4          0     .     =
```

科学模式下各键变成：

| 按键 | 普通 | 科学 | 按键 | 普通 | 科学 |
|:---:|:---:|:---:|:---:|:---:|:---:|
| 7 | 7 | `(` | 4 | 4 | `sin`（长按切换） |
| 8 | 8 | `)` | 5 | 5 | `cos`（长按切换） |
| 9 | 9 | `!` | 6 | 6 | `tan`（长按切换） |
| ÷ | ÷ | `^`（长按可切 `,`） | − | − | `e` |
| × | × | `π` | 1 | 1 | 对数（长按切换） |
| 2 | 2 | `%` | 3 | 3 | `Ans` |
| + | + | `±` | 0 | 0 | DEG / RAD |
| . | . | `his` | C / ⌫ / = | 不变 | 不变 |

方屏是 5 行 × 4 列，换字规则与上表完全一样，只是按键排布不同。

### 长按可选：函数键与乘方键
科学模式下 `1`(对数)、`4`(`sin`)、`5`(`cos`)、`6`(`tan`)、`÷`(`^`) 五个键都支持**长按**弹出选择气泡：

- 对数键：`ln` / `lg` / `log(底数, 真数)`（底数和真数之间用逗号，逗号从 `^` 键长按切出来）
- `sin`：`sin` / `asin` / `sinh` / `asinh`；`cos`、`tan` 同理（`cosh`/`acosh`、`tanh`/`atanh`）
- 乘方键：`^` / `,`（算式里的逗号只能从这里切过来，例如 `log(2,8)`、`root(3,27)`；
  换过去之后这个键就变成逗号键，再长按一次可以换回 `^`）

气泡浮在**按键区上方那片空白里、水平居中**，选项并排全部显示，点哪个选哪个，
选中的一项高亮；按键上显示的就是当前选中的短名（例如 `asinh`），按下去会连左括号一起输入。
气泡带缩放弹出动画，点气泡以外的地方收起。

### Ans：把上一题的结果接着算
科学模式下 `3` 键变成 `Ans`，按下去就把上一题的答案填进算式：
`2Ans`、`Ans^2`、`Ans+1`、`sin(Ans)` 都行。算式里显示为 `ans`。
刚打开还没算过任何东西时 `Ans` 等于 `0`。退格会整块删掉 `ans`。

### ± ：翻转最右边那个数的正负
科学模式下 `+` 键变成 `±`。点一下就把算式里**最右边那个数**取反：
`5` → `-5`、`5+3` → `5+-3`、`5-3` → `5--3`、`5×3+2` → `5×3+2`（在最右的 2 上取反）。

### his：历史记录
科学模式下 `.` 键变成 `his`，点开是历史页面（盖在计算器上面，不是新开一个页面）：

- 最底下固定一个 `his` 按钮，**再点一次回到计算页**；**长按 `his` 按钮清空全部记录**；
- `his` 上面是记录开关：默认显示 `记录历史`（照常记录），点一下变成 `不记录历史`，之后的运算不再写进历史；
- 中间是历史列表，每条显示算式和结果，可以**上下滑动**，圆屏上**转表冠也能滚**；
- **长按某一条记录就删掉那一条**（只影响这一条，其余照旧）。

### 角度单位 DEG / RAD
科学模式下 `0` 键直接显示当前角度单位（`DEG` 或 `RAD`），点一下就在两者之间切换，
切换时历史行会给一句提示（所有提示都是 2 秒后自动清空）。
默认是角度制：科学模式下依次按 `4` `3` `0` `=` 得到 `0.5`（`4` 是 `sin`）。

### 括号可以多层嵌套
`(` 是 `7` 键、`)` 是 `8` 键，随便套多少层都行，例如
`((1+(2×(3+(4×5)))))` = `47`；`)` 只有在还有没配对的 `(` 时才会按下去。
**少写右括号不算错**：`sin(30` 会按算式结束的位置自动补齐成 `sin(30)` = `0.5`，
`sin(30+cos(60` 也能正确算成 `0.5075…`。多写右括号仍然会报错。

### 支持的运算
- 四则：`+` `-` `×` `÷`
- 乘方：`^`（右结合，`2^3^2 = 512`；`-2^2 = -4`）
- 括号：`(` `)`
- 阶乘：`!`（`5! = 120`，上限 2000）
- 取模与百分号：`%`（`7%2 = 1`；`50% = 0.5`）
- 三角函数：`sin` `cos` `tan`，逆三角 `asin` `acos` `atan`（单位跟随 DEG/RAD）
- 双曲与反双曲：`sinh` `cosh` `tanh` `asinh` `acosh` `atanh`
- 对数：`ln` `lg` `log(底数, 真数)`（`log(8)` 只写一个参数时是常用对数 `lg(8)`；
  带底数写逗号，例如 `log(2,8) = 3`，逗号从 `^` 键长按切出来）
- 常量：`π`、`e`
- 隐式乘法：`2π`、`3(4+5)`、`2sin(30)` 都会被自动理解为乘法

引擎内部另外还实现了 `sqrt` `cbrt` `root` `inv` `abs` `exp` `pow` `sinh` `cosh` `tanh`，
后续要加新按键时可以直接接上。

所有实数运算都在 30 位有效数字的 `BigDecimal` 上完成（结果默认保留 8 位小数，极小的数走科学计数法）：
圆周率由 Machin 公式现场算出，三角函数用泰勒级数、对数用 atanh 级数、开方用牛顿迭代，
全程不经过 `double`，所以 `sin(30)` 得到的是干净的 `0.5`，而不是 `0.49999999999999994`。
`tools/` 目录下是配套的纯 Java 验证程序（不属于 app 构建），可以直接跑数学用例。

## 📥 下载与安装 (Installation)
**直接安装**：
>前往 **微思应用商店** 手表端，搜索“嗷呜计算器”下载安装。

**ADB手动安装**：
>1.  前往 [Releases](https://github.com/NickWoluff/WearCalculator/releases) 页面下载最新版本；
>2.  确保你的手表已开启**开发者模式**和**ADB 调试 / 无线调试**；
>3.  使用adb工具（如甲壳虫ADB助手、WearOS工具箱）或电脑端 ADB 命令行将 APK 推送到手表：
    ```bash
    adb install WearCalculator_vX.X.X.apk
    ```
